페이지 매뉴얼 설정

작성된 매뉴얼이 없는 화면에서 AI 매뉴얼을 만들 때 쓰는 설정입니다. 설정은 이 브라우저에만 저장됩니다.

Claude API 키

AI 매뉴얼은 본인의 API 키로 Claude API를 직접 호출합니다. 키는 이 확장의 로컬 저장소에만 두고 다른 곳으로 보내지 않습니다.

모델

기본값은 빠르고 저렴한 모델입니다. 목록에 없는 모델 ID도 입력할 수 있습니다.

AI 매뉴얼 생성 허용 사이트

여기 있는 사이트에서만, 작성된 매뉴얼이 없을 때 화면 구조(제목, 메뉴, 버튼·입력란 이름, 표 머리글, 안내 문구)를 Claude API로 보냅니다. 입력한 값, 비밀번호, 표 내용, 주소의 검색어는 보내지 않습니다.

    작성 매뉴얼 사이트

    작성된 매뉴얼은 권한 없이도 보입니다. 「화면에서 보기」로 요소를 표시하려면 사이트 접근 권한이 필요합니다.
