다음은 Chrome 확장 「페이지 매뉴얼」(업무 시스템 화면마다 그 화면의 역할·기능·조작 방법을 사이드 패널로 보여 주는 확장) 48초 소개 영상의 화면 카피다. 나레이션은 없고 화면 글자가 전부다.
기준:
1. 번역투·어색한 리듬·어색한 조어를 찾아 고칠 것
2. 한 화면에 1.5~3초 동안 보이므로 글자 수를 늘리지 말 것(줄이는 건 좋다)
3. 사실(기능 설명)은 바꾸지 말 것
4. 파일을 읽거나 명령을 실행하지 말고 `| ID | 원문 | 제안 | 이유 |` 표로만 답할 것. 고칠 것이 없으면 그 줄은 빼라.
