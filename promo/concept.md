# 콘셉트 — 페이지 매뉴얼 소개 영상

- 요청: "소개 영상을 만들어서 README.md 에 첨부해줘" (/showreel)
- 대상: 이 저장소의 Chrome 확장 「페이지 매뉴얼」. 사실은 코드·QA 기록에서 직접 확인했다(조사 서브에이전트 불필요).
- 한 문장 아이디어: **처음 보는 업무 화면 앞의 막막함이, 옆에 펼쳐지는 설명서 한 장으로 풀린다.** 영상 속 제품 화면은 실제 확장을 로드해 찍은 스크린샷이다.
- 길이·규격: 48초 · 16:9 1920×1080 · 30fps · 음악 120 BPM(1마디 2초, 섹션 4마디 = 8초)
- 나레이션: 없음. README에서 대부분 소리 없이 자동 재생·미리보기로 보므로 화면 카피로 전한다.
- Claude가 정한 것: 길이 48초(README 소개용으로 60초는 길다, 24마디로 마디에 맞음), 나레이션 없음, 생성 이미지 없음(실제 스크린샷이 더 정직한 증거), 팔레트는 확장 UI의 실제 색 토큰.
